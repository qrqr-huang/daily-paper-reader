## 摘要
嵌入式软件旨在实时提供电池的主要特性，以管理和优化电池使用。完整的多维模型在现场可用的低计算资源下难以求解。从P2D Doyle-Fuller-Newman系统出发，通过对函数空间形状的额外假设，推导出一类空间零维模型，在保留主要时间特性的同时大幅降低复杂度。我们基于Butler-Volmer源项在每个子域（负极、隔膜、正极）内恒定的假设，从P2D系统构建了一个守恒且保正性的模型。我们建立了数学上严格的构造，给出简化模型，并设计了求解该系统的数值格式。我们强调该模型保证了守恒性以及浓度的正性。特别是，明确给出了扩散限制电流密度，它表示在仍保持阳离子浓度正性的前提下可使用的最大电流。

## Abstract
Embedded software aims to provide the main characteristics of a cell in real time to manage and optimize battery usage. A complete multidimensional model is not tractable with the low computational resources available in-situ. A class of 0D-in-space models is derived from the P2D Doyle-Fuller-Newman system, with additional assumptions about the functions' shape in space, and strongly reduces the complexity while preserving the main characteristics over time. We propose a conservative, positivity-preserving model built from the P2D system based on the statement that the Butler-Volmer source term is constant in each subdomain (anode, separator, cathode). We develop a mathematically rigorous construction that provides the simplified model and design a scheme to solve the system. We highlight that the model guaranties the conservation property together with the positivity of the concentrations. In particular, the diffusion-limited current density that represents the maximum current that can be used while still preserving the positivity of the cation concentration is obtained explicitly.

### 2.2 关键技术细节

- **电极物种守恒**：对颗粒径向扩散方程积分，得到平均浓度演化  
  \[
  \varepsilon_n \frac{d\bar{c}_n}{dt} = -\frac{\bar{j}^{BV}_{en}}{F}, \quad
  \varepsilon_p \frac{d\bar{c}_p}{dt} = -\frac{\bar{j}^{BV}_{ep}}{F}
  \]
  其中 \(\bar{j}^{BV}_{ek}\) 是电极内平均 Butler-Volmer 体积电流密度。

- **电解质浓度**：在准稳态假设下，电解质浓度方程变为纯扩散型，可解析积分。平均浓度与界面浓度均表示为**电流 I 的线性函数**，时间依赖仅通过 \(I(t)\) 体现。

- **电子/离子电流与电位**：由 Butler-Volmer 源项常数假设，电子电流和离子电流在空间上呈线性，电位呈二次型。通过梯形公式得到平均电位与界面电位的关系。

- **扩散限制电流密度**：由于浓度在集流体界面处取极值，要求浓度非负，导出一个容许强度区间  
  \[
  I \in [I^-_e, I^+_e]
  \]
  其中 \(I^+_e\)（放电上限）和 \(I^-_e\)（充电下限）由浓度函数为仿射性质显式求得：
  \[
  I^-_e = \frac{c^0_e}{c^0_e - \hat{c}^{1}_{en,c}} < 0, \quad
  I^+_e = \frac{c^0_e}{c^0_e - \hat{c}^{1}_{ep,c}} > 0
  \]

- **Butler-Volmer 方程与 b-双曲函数**：引入 b-hyperbolic 函数  
  \[
  \operatorname{bsinh}(x,\beta) = \frac{e^{2\beta x} - e^{2(\beta-1)x}}{2}
  \]
  及其逆函数 \(\operatorname{arg bsinh}\)，用于从电流反解过电位。文中证明该函数是 \(\mathbb{R}\to\mathbb{R}\) 的双射，并给出 Newton 法求逆。

- **电位分解与非线性方程**：将电池端电压差分解为  
  \[
  \Phi_{cp} - \Phi_{cn} = U_{ep} + \eta_{ep} - U_{en} - \eta_{en} - R_{int}I - \Delta_c
  \]
  其中 \(R_{int}\) 为内阻，\(\Delta_c\) 为浓度梯度引起的电位降。结合外电路关系 \( \Phi_{cp}-\Phi_{cn} = R_{ext}I + U_{ext} \)，得到关于强度 I 的非线性方程  
  \[
  V_{res}(I,R_{ext}) = U_{ep}-U_{en}-U_{ext}-\Delta_c - (R_{ext}+R_{int})I - \frac{2}{f}\left[\operatorname{arg bsinh}\!\left(\frac{I}{\iota_n}\right) + \operatorname{arg bsinh}\!\left(\frac{I}{\iota_p}\right)\right] = 0
  \]
  并证明对任意 \(R_{ext}\ge 0\) 存在唯一解。

### 2.3 数值算法流程

- **浓度更新**：用前向 Euler 更新电极平均浓度，电解质浓度由代数关系直接计算。
- **电位/强度求解**：  
  1. 计算 \(V_{00}=V_{res}(0,0)\) 判断充放电状态；  
  2. 检查目标强度 \(I_0\) 是否在扩散限制区间内；  
  3. 若目标强度可达，计算所需外电阻 \(R_{ext}=V_{res}(I_0,0)/I_0\)；  
  4. 若不可达，令 \(R_{ext}=0\)，用数值方法（二分法或 Newton 法）求 \(V_{res}(\bar{I},0)=0\) 的解 \(\bar{I}\)，且保证 \(\bar{I}\) 在扩散限制区间内。

## 摘要
单体间的电学和热学差异导致锂离子电池组中荷电状态（SoC）和温度分布不均匀。本文提出一种基于Koopman算子的框架，用于串联电池单体SoC和温度的同时均衡。利用扩展动态模态分解辨识得到的单体特定Koopman预测器被组装成相邻单体误差动力学，该动力学保留了异质性和热扰动效应。Tikhonov正则化的前馈控制器在不过度放大电流的情况下提供数值鲁棒的补偿，而带约束的基于Koopman的模型预测控制（KMPC）通过凸二次规划调节残余误差。三单体仿真在连续两个城市测功机驾驶循环下验证了控制器。KMPC实现了与非线性模型预测控制（NMPC）相当的均衡性能。与未控制情况相比，KMPC将相邻单体SoC和核心温度差异的RMSE分别降低了66-81%和57-76%，同时将每次优化的计算时间从NMPC的0.0259s降至KMPC的0.0028s。

## Abstract
Cell-to-cell electrical and thermal variations produce nonuniform state of charge (SoC) and temperature distributions in lithium-ion battery packs. This paper proposes a Koopman-operator-based framework for simultaneous SoC and temperature balancing of series-connected cells. Cell-specific Koopman predictors identified using extended dynamic mode decomposition are assembled into neighboring-cell error dynamics that retain heterogeneity and thermal-disturbance effects. A Tikhonov-regularized feedforward controller provides numerically robust compensation without excessive current amplification, while constrained Koopman-based model predictive control (KMPC) regulates the residual errors through a convex quadratic program. Three-cell simulations validate the controller under two consecutive Urban Dynamometer Driving Schedule cycles. KMPC achieves balancing performance comparable to nonlinear model predictive control (NMPC). Relative to the uncontrolled case, KMPC reduces the RMSEs of the neighboring-cell SoC and core temperature differences by 66-81% and 57-76%, respectively, while reducing the computation time per optimization from 0.0259s for NMPC to 0.0028s for KMPC.

- **整体意义**：本文利用 Koopman 算子理论，将非线性电热动态在提升的观测空间中近似为线性系统，从而把多单体均衡问题转化为可通过凸二次规划在线求解的预测控制问题，降低了在线计算负担同时保持接近 NMPC 的均衡表现。

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

### 2.1 单体电热建模

- 每个单体采用 **一阶 Thevenin 等效电路模型（ECM）** 描述电学动态：
  - 状态：SoC 和极化电压 \(V_c\);
  - 输出：端电压 \(V = OCV(SoC) - V_c - I R_0\)，其中 OCV 为非线性函数。
- 热学动态采用 **两状态集总参数模型**：
  - 状态：核心温度 \(T_c\) 和表面温度 \(T_s\);
  - 热源：\(Q_{gen} = I(OCV - V)\)，包含非线性电热耦合。
- 单体总状态维度：\(x_i = [SoC_i, V_{c,i}, T_{c,i}, T_{s,i}]^\top\)，输入为电流 \(u_i = I_i\)，扰动为环境温度 \(d_i = T_{f,i}\)。

### 2.2 Koopman 算子辨识（核心思想）

- 使用 **扩展动态模态分解（EDMD）** 将非线性映射 \(f_i\) 投影到有限维观测空间：
  \[
  z_i(k+1) = A_i z_i(k) + B_i u_i(k) + E_i d_i(k), \quad \hat{x}_i(k) = C_i z_i(k)
  \]
- **提升字典**：\(\Psi(x) = [x^\top, \psi_1(x), \psi_2(x), \psi_3(x)]^\top\)，其中三个 RBF 核 \(\psi_\ell(x) = \exp(-\lVert x - c_\ell \rVert^2 / 2\sigma^2)\) 用于捕捉非线性，观测空间维度 \(N_o = 7\)。
- 矩阵通过最小二乘/伪逆从非线性电热仿真数据中辨识：
  \[
  [A_i, B_i, E_i] = Y_{lift,i}
  \begin{bmatrix} X_{lift,i}\\ U_i\\ D_i \end{bmatrix}^\dagger, \quad C_i = X_i X_{lift,i}^\dagger
  \]
- 关键前提：**假设 1** 假设单体参数已知且在工作区间内恒定，将辨识误差排除在控制器设计之外。

### 2.3 相邻单体误差动力学

- 控制目标：相邻单体状态趋于一致，\(\lim_{k \to \infty} \lVert x_i(k) - x_{i+1}(k) \rVert = 0\)。
- 定义提升误差：\(\delta_i(k) = z_i(k) - z_{i+1}(k)\)，组装全局误差动力学：
  \[
  \Delta(k+1) = A_\Delta \Delta(k) + B_\Delta U(k) + A_\Delta Z(k) + E_\Delta D(k)
  \]
  其中包含单体间参数失配项 \(A_\Delta\) 和热扰动项 \(E_\Delta\)。

### 2.4 复合控制器设计

- 输入分解：\(U(k) = U_{nom}(k) + \bar{U}(k) + \tilde{U}(k)\)，分别为名义电流、反馈均衡电流、前馈补偿电流。
- **Tikhonov 正则化前馈**：由于 \(B_\Delta\) 可能病态（热扰动仅通过表面温度作用，伪逆存在小奇异值放大问题），求解：
  \[
  \min_{\tilde{U}} \frac{1}{2}\lVert B_\Delta \tilde{U} + H(k)\rVert_2^2 + \frac{\lambda}{2}\lVert \tilde{U}\rVert_2^2
  \]
  解析解为 \(\tilde{U} = -(B_\Delta^\top B_\Delta + \lambda I)^{-1} B_\Delta^\top H(k)\)，通过正则化限制电流放大。
- **假设 2**：假定补偿残差可忽略，得到线性误差动力学：
  \[
  \Delta(k+1) = A_\Delta \Delta(k) + B_\Delta \bar{U}(k)
  \]

### 2.5 KMPC 在线优化

- 在每个采样时刻求解二次规划：
  \[
  \min_{\bar{U}} \sum_{j=0}^{N_p-1} (\lVert \Delta(j|k)\rVert_Q^2 + \lVert \bar{U}(j|k)\rVert_R^2) + \lVert \Delta(N_p|k)\rVert_P^2
  \]
  受线性预测动态和电流约束 \(\bar{U}_{min} \le \bar{U} \le \bar{U}_{max}\) 约束。
- 由于目标为二次型、动力为线性、约束为仿射，构成**凸 QP**，存在唯一全局最优解，用 `quadprog` 高效求解。
